# REA: Reverse Engineers Anything

A Cowork plugin that helps you understand how software, file formats, protocols, APIs and devices work from the artifacts you provide.

## Use

- Command: `/rea [file, log, URL or description]`
- Or just ask Claude to analyze, decode or document something; the `reverse-engineer` skill triggers automatically.

## Scope

For authorized, legitimate analysis only (interoperability, learning, security research with permission, recovering your own data).
